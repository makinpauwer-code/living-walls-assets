# Living Walls — Dynamic Asset Library

Colección de 30 fondos verticales animados en SVG (1080×1920), con 8 categorías y catálogo JSON.

- Galería: https://makinpauwer-code.github.io/living-walls-assets./
- Catálogo: assets.json
- Integración: GROK_INTEGRATION.md
- Derechos: LICENSE.txt

Todos los SVG se han creado proceduralmente desde cero para este proyecto, sin incorporar imágenes o recursos de terceros. Los SVG contienen animaciones en bucle; la app Android debe reproducirlos mediante un renderer compatible dentro de WallpaperService para que sean fondos dinámicos reales.
